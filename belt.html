Belt

Position unknown

Hold buttons run the belt only while pressed (mouse or finger) and stop when you let go, then tighten. "Tighten" makes both spools pull against each other for a moment — it also happens by itself after every move.

Find START: the board runs down until it sees START's long mark — from anywhere, even right after switching on. It learns how long an ordinary mark is from steps down, so after a fresh flash: put the paper on START, press "It's on START now", step up twice and down once.

Service mode (lid on, no laptop): hold YES + NO for 5 s (or A + B). The micro:bit shows S. Hold YES = wind up, hold NO = wind down, coin = find START. Hold YES + NO 5 s again to leave.

Light sensor

–
Set by itself halfway between paper and mark; you can type your own. Red line on the bar. How far above the threshold the light must rise before it counts as "off the mark". Off = each step runs for a fixed time.

While the belt moves, the board sends the light reading every 20 ms. Yellow = the reading; red = threshold (below = mark); orange = threshold + hysteresis; ticks = what the board decided (green: mark, grey: flicker ignored). "Send log to the Mac" includes these readings.

Motors & tension

Lower than the pulling speed keeps the paper tight. Tick if "wind in" lets paper out instead. Flips that motor everywhere — no rewiring needed. Every start gets a short burst of full power so the motor breaks loose. 0 = off. Find START never passes more marks than this. Moves also stop after about 1.5 screens of paper without a mark, so a missed mark can't unwind the paper off a spool. A short burst backwards when the mark is seen, so the spools don't coast past it. 0 = coast. After stopping and tightening, creep until the sensor is on the mark again — every screen ends in the same place. The board remembers which way worked and tries that first.

Changes go to the micro:bit straight away, and it keeps them even after a restart.

Bell

Tick if the bell rings all the time while idle and stops when it should ring.

Wiring: relay module IN → P2 (S pin), VCC → the Wukong's 5V pin, GND → G. On the relay's other side: 9 V battery − → COM, NO → bell, bell's other wire → battery +. Never the bell straight on P2.

Backlight (LED matrix)

Start low (about 25) when powered from the Wukong — above about 40 the LEDs pull so much current that the micro:bit can stumble and drop the connection (it did at 120, 2026-10-14). Keep it steady — the light sensor reads it, so recalibrate after changing it. Pick by looking at the box — the LEDs' green is much stronger than on a screen. Changes live. Check paper/mark on the light sensor afterwards.

Wiring: matrix IN → P15 (yellow S pin), V- → G, V+ → the Wukong's 5V pin in the middle header (the red pin rows are only 3.3 V). For the festival: a separate 5 V supply, GND joined to the Wukong's.
