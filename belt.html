Set by itself halfway between paper and mark; you can type your own. Red line on the bar. How far above the threshold the light must rise before it counts as "off the mark". Off = each step runs for a fixed time.

Motors & tension

Lower than the pulling speed keeps the paper tight. Every start gets a short burst of full power so the motor breaks loose. 0 = off.

Changes go to the micro:bit straight away, and it keeps them even after a restart.

Backlight (LED matrix)

Start low (about 25) when powered from the Wukong. Keep it steady — the light sensor reads it, so recalibrate after changing it.

Wiring: matrix IN → P15 (yellow S pin), V- → G, V+ → the Wukong's 5V pin in the middle header (the red pin rows are only 3.3 V). For the festival: a separate 5 V supply, GND joined to the Wukong's.
